# Negative Images / Imágenes Negativas


This folder contains negative images used to train a custom Haar Cascade classifier.

Negative images must:
- **Not contain** the object of interest.
- Include diverse backgrounds, environments, and lighting conditions.
- Contain different textures, shapes, and objects.
- Have no annotations or bounding boxes.
- Be saved in a supported image format (JPG, PNG, BMP).

A greater image diversity helps reduce false positives and improve classifier performance.

---


Esta carpeta contiene las imágenes negativas utilizadas para entrenar un clasificador Haar Cascade personalizado.

Las imágenes negativas deben:
- **No contener** el objeto de interés.
- Incluir fondos, entornos y condiciones de iluminación variados.
- Contener diferentes texturas, formas y objetos.
- No tener anotaciones ni cuadros delimitadores (*bounding boxes*).
- Estar guardadas en un formato de imagen compatible (JPG, PNG, BMP).

Una mayor diversidad de imágenes ayuda a reducir los falsos positivos y mejorar el rendimiento del clasificador.
