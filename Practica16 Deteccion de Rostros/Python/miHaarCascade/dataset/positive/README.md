
# Positive Images / Imágenes Positivas

This folder contains positive images used to train a custom Haar Cascade classifier.

Positive images must:
- **Clearly contain** the object of interest.
- Show the object from different angles, scales, and positions.
- Include variations in lighting, rotation, and appearance.
- Have the object properly annotated using bounding boxes.
- Be saved in a supported image format (JPG, PNG, BMP).

A diverse set of positive samples helps the classifier recognize the target object under different conditions.

---

Esta carpeta contiene las imágenes positivas utilizadas para entrenar un clasificador Haar Cascade personalizado.

Las imágenes positivas deben:
- **Contener claramente** el objeto de interés.
- Mostrar el objeto desde diferentes ángulos, escalas y posiciones.
- Incluir variaciones de iluminación, rotación y apariencia.
- Tener el objeto correctamente etiquetado mediante cuadros delimitadores (*bounding boxes*).
- Estar guardadas en un formato de imagen compatible (JPG, PNG, BMP).

Un conjunto diverso de muestras positivas ayuda al clasificador a reconocer el objeto objetivo bajo diferentes condiciones.
